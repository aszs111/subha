# سُبحة

تطبيق أندرويد للتسبيح والذكر: خيط عليه خرزات تسقط واحدة تلو الأخرى بتمرير الإصبع، مع صوت فرقعة الخرز.

- الشاشة الرئيسية: خلفية خضراء ملكية، الخرز على اليمين (ثلاث فوق وثلاث تحت وبينهما فراغ)، والذكر على اليسار.
- الضغط على الذكر ← قائمة الأذكار (إضافة وتعديل وحذف وترتيب، ولكل ذكر عدده المطلوب).
- الضغط على الخرز ← اختيار شكل الخرز (١٢ شكلًا).
- الإعدادات: الصوت، الاهتزاز، إبقاء الشاشة مضاءة، الخطة (عدد المرات)، والانتقال التلقائي للذكر التالي.
- زر «إعادة» مع إمكانية التراجع.

يُبنى ملف APK تلقائيًا عبر GitHub Actions، ويُنشر في Releases.
